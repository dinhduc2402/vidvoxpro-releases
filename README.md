# VidVox Pro — bản cài

Kho này chỉ chứa **bản cài Windows** và kênh cập nhật tự động của VidVox Pro.
Mã nguồn nằm ở kho riêng, không công khai.

## Tải về

Bản mới nhất luôn ở trang [Releases](../../releases/latest). Tải file
`VidVox Pro_<phiên bản>_x64-setup.exe` rồi chạy.

Ứng dụng tự kiểm tra bản mới qua `latest.json` trong release mới nhất, nên sau
lần cài đầu tiên bạn không cần quay lại đây nữa.
